# 光匣 · FilmPhotoManager

按胶卷整理冲洗后的电子照片，在本机浏览、归档和打印整卷接触印样。当前版本 **1.3.1**。

## 快速开始

需要 **macOS** 和 **Node.js 20 或更新版本**，无需安装第三方 npm 依赖。TIFF 浏览预览使用 macOS 自带的 `sips`，自动方向识别使用本机 Vision。

```bash
git clone https://github.com/zhbuaa0/FilmPhotoManager.git
cd FilmPhotoManager
npm start
```

浏览器打开 [http://127.0.0.1:4317](http://127.0.0.1:4317)。也可以双击“打开光匣.command”；请保留启动窗口，停止时按 Control+C。

## 已实现

- **按卷归档**：记录名称、实物编号、相机、胶卷型号、ISO、规格、上卷时间、拍摄跨度、冲洗时间、冲洗店和备注。直接在胶卷页编辑并自动保存。
- **导入扫描照片**：支持 TIFF、JPG、PNG、WebP 和 GIF，单张不超过 80 MB；批量文件夹导入、引用原目录或复制原图、重复文件跳过。
- **扫描原片与成片关联**：使用 JPEG 的 XMP 原文件名匹配 TIFF，THM 辅助文件自动忽略；同一帧支持多个版本。
- **照片浏览**：接触印样网格、放大查看、星标精选、拖动帧序、手动旋转及原图下载。
- **连续胶片条**：带连续齿孔、卷头卷尾和帧号，支持拖动、滚轮、触屏、键盘、定位滑杆与自动走片。
- **本机方向识别**：按人脸和文字朝向给出旋转建议，提供前后对照、待确认筛选、批量应用、手动方向保护和撤销；照片不上传，原文件不改写。包含 Apple 芯片 Mac 可执行文件，其他架构首次使用需 Apple 命令行开发工具编译。
- **打印预览**：整卷 PNG 接触印样，横向 3:2（3600 × 2400）、横向 16:9（3840 × 2160）及按内容自动适配，照片完整显示。

完整操作、导入和备份说明见 [使用说明](使用说明.md)。

## 保存与备份

首次启动自动创建 `data/`，其中保存档案、照片副本、独立缩略图和导出预览。该目录被 Git 忽略，仓库不包含个人胶卷档案或照片。

- 备份前先停止软件，再复制整个 `data/`。
- 使用“引用原目录”时，还需备份源胶片文件夹并保持引用路径可用。
- 软件只在 `127.0.0.1` 提供本机服务，面向个人使用。
- 旧版本的 SQLite 档案与当前 JSON 档案格式不同，目前没有自动迁移工具；旧档案请保留备份。

## 开发与检查

```bash
npm test
```

检查覆盖档案保存恢复、文件夹导入、XMP 关联、源文件保护、方向建议及撤销、打印布局。部分检查调用 macOS 原生图像工具，需要在 Mac 上运行。

```text
server.mjs              本机 HTTP 服务和档案保存
local-import.mjs        文件夹检查、照片关联和导入
orientation.mjs         方向判断、应用与撤销
public/                 页面、样式、交互和打印排版
native/                 macOS Vision 引擎源码及 Apple 芯片程序
tests/                  自动检查
使用说明.md             操作与备份说明
打开光匣.command         Mac 启动入口
```

本次更新以当前光匣软件替换旧的 Flask / React 实现，原版本仍保留在 Git 提交历史中。
