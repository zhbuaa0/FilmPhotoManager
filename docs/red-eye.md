# 本机去红眼

1.12.0 加入本机去红眼。照片不上传，原始扫描文件保持只读。自动检测是保守的辅助工具；小脸、眼镜反光、颗粒和偏色可能漏检，导出前请检查眼部对照。

## 使用

打开照片，点击「一键去红眼」；也可在胶卷详情勾选照片后点「选中去红眼」，或点「整卷去红眼」。处理采用当前成片 / 扫描原片偏好；放大窗口单张处理使用正在查看的具体版本。

结果中，可靠候选默认启用，疑似候选保持关闭。每只眼睛都有原图 / 修正后放大对照，可以勾选、调整强度和范围、删除选区。漏检时打开「手动点选」，点击原图的红色瞳孔；可放大至 2 倍 / 4 倍，并调整搜索范围。没有识别人脸时也允许手动补选。重复点击同一个瞳孔替换选区，不叠加修正。

「显示修正版」控制接触印样、胶片条和新生成的整卷预览；照片放大窗口另有修正版开关。「复制原图」和「下载原图」始终提供原文件。修正版以原分辨率、无损 Deflate TIFF 导出，Windows 还支持多选「复制修正版」，然后在文件资源管理器粘贴。所选版本必须都有有效修正，否则停止整批复制并提示。

「撤销这批修正」恢复这批自动检测前的记录，跳过之后手动修改过的照片。「撤销本张修正」先恢复本轮手动修改前的选区；再次点击可移除检测记录。重新检测可通过整批撤销恢复先前记录。撤销不删除源照片，已经导出或粘贴的文件不会随撤销改变。

任务在 Node 服务后台执行；关闭弹窗或浏览器后继续，停止服务则暂停执行，下次启动自动恢复未完成任务。「取消剩余任务」保留已完成结果；当前正在计算的一张完成后丢弃结果，再停止剩余项。

## 实现与数据

- `red-eye-detector.mjs`：离线 YuNet 人脸 / 眼睛定位，sRGB 检测代理采用全图及重叠分块；规范坐标以 EXIF 归正后的图像为基准，显示旋转在点选时反变换。
- `red-eye-mask.mjs`：独立实现局部红色优势、连通区域、形状和位置判断。只在眼部椭圆内抑制红通道并羽化，保留中性高光与原始纹理。没有生成新眼睛，不处理宠物黄眼 / 绿眼。
- `red-eye-render.mjs`：从源版本重新读取 8-bit / 16-bit RGB 像素；母版保留位深、ICC 和密度，应用显示旋转后写入 Orientation=1。无 ICC 的 RGB 按 sRGB 解释；CMYK 请先转 RGB。不会把整份源 EXIF / IPTC / XMP 复制到新 TIFF，原文件保留这些信息。
- `tiff-profile.mjs`：仅给自己生成的单页标准 TIFF 附加源 ICC，不执行二次全图色彩转换。RGB、未旋转母版的选区及羽化区域外像素保持一致；JPEG 浏览预览经过 sRGB 转换、缩放和重编码，不承诺逐像素相同。
- `red-eye-service.mjs` / `red-eye-worker.mjs`：独立 Worker，图像任务串行执行，CPU 推理，单项超时 180 秒。单图上限 8000 万像素；超大扫描仍可能需要较多内存。模型加载失败或单张源文件离线会显示错误并继续其他项。

每张照片的 `redEye[versionId]` 保存在 `data/library.json`，绑定源文件 SHA-256、尺寸、方向坐标系、修订号、选区与强度。处理前后校验文件，源发生变化时要求重新检测。浏览缓存同时绑定版本、修订号、旋转角度和输出规格。

`data/red-eye/jobs.json` 保存最近 80 批任务及撤销快照；`data/red-eye/renders/` 是可重建缓存，`data/clipboard/` 保存供 Windows 粘贴的文件。备份修正记录需要备份整个 data；引用导入还需保留原目录。缓存和已导出文件暂不自动清理。

## 模型与来源

YuNet 2026may 动态输入模型来自 [OpenCV Zoo](https://github.com/opencv/opencv_zoo/tree/main/models/face_detection_yunet)，随仓库分发；下载地址、大小与 SHA-256 记录在 [manifest](../models/red-eye/manifest.json)，运行时核对哈希。其 MIT 许可证保存在 [LICENSE](../models/red-eye/LICENSE)。推理依赖固定为 `onnxruntime-node@1.31.1`，见 [官方 Node 平台支持](https://onnxruntime.ai/docs/get-started/with-javascript/node.html)。安装依赖需要联网，安装完成后的检测与修正不访问外部接口。

项目 `.npmrc` 将 `onnxruntime-node-install` 设为 `skip`，仅跳过额外的 CUDA / TensorRT 下载；CPU 原生绑定仍由 npm 包提供并接受真实模型测试。请保留这个配置，避免 Linux 默认安装流程尝试下载本应用不使用的 GPU 库。

交互参考 [GIMP 去红眼](https://docs.gimp.org/3.0/en/gimp-filter-red-eye-removal.html) 的局部选择 / 阈值思路，以及成熟照片管理软件的批量检测、人工核对流程。颜色分割及修正代码自行实现，未移植 GPL 滤镜源码。

## 验证范围

自动检查覆盖局部修正、选区外像素、高光、四向坐标、EXIF 归正、8-bit / 16-bit TIFF、P3 ICC、BMP、源哈希、照片版本隔离、重复补选、HTTP 导出、取消、撤销及重启恢复。另在 Windows 实测自动候选、手动补选、眼部对照和文件剪贴板。

目前用合成红瞳孔及公开示例验证流程，尚未完成 50–100 张真实胶片照片的独立质量评测。人脸检测精度不代表去红眼精度；不宣称全自动消除所有红眼。真实扫描的误修 / 漏检率及自然度仍需代表性样本核对。
