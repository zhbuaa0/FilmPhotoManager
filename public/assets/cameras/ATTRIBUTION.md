# Camera reference photographs

These model reference photographs are bundled for offline display. They depict reference equipment, not the user's own cameras. Personal uploads are saved only in the ignored `data/camera-images/` folder.

All three images have been resized to fit 1200 × 1000 pixels and converted to WebP. No cropping or compositing was applied. The resulting image files retain the licenses listed below; these image licenses do not change the license of the application source code.
